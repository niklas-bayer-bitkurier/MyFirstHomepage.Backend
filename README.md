# My first homepage - Backend

### Import frontend
1. Make sure you are in root directory of the backend, then run:
```shell
mkdir frontend && cd frontend
```
2. Then clone the frontend with:
```shell
git clone https://github.com/niklas-bayer-bitkurier/MyFirstHomepage.git
```
3. To open the homepage, navigate to \[domain\]/frontend/MyFirstHomepage/index.html
